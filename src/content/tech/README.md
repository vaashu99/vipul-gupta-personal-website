# Tech writing

This collection holds professional writing, engineering notes, community
participation and learning milestones. Personal writing belongs
in `src/content/journal`, organized as Thoughts & Conversations, Life Notes,
What If and Humour. My Space is the separate hub for Travel, Photos and Memories.

Categories: `engineering`, `community`, `learning`. Use lowercase hyphenated
Markdown filenames; nested directories are supported. The article metadata,
cover-image rules and draft/future publication gates match Journal. See
[the authoring guide](../../../docs/blog-authoring.md) for the workflow.

Website publication dates must be clearly distinguished from event or credential
dates when those differ. Keep claims source-backed and link the original source.
Do not invent dates, quotes, personal takeaways, production metrics or tutorials.
